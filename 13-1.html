Font Awesome 图标 — 字体图标方式

练习 13-1 ｜ 资源来源：本地 cdn/fontawesome/（CSS + webfonts 字体文件）
说明：Font Awesome 采用「字体图标」方案——先把图标做成字体（webfonts/fa-*.woff2），再通过 CSS 给 <i> 元素指定字体与字符编码（如 .fa-home::before{content:"\f015"}）来显示图标。 使用时引入 cdn/fontawesome/css/all.min.css，在标签上写 class="fa-solid fa-图标名" 即可，图标本质上是文字，可像文字一样用 CSS 控制大小、颜色。
