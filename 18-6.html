基于 Mermaid 的智能客服系统

图一：智能客服系统业务流程图　图二：智能客服系统数据库 ER 图

图一　智能客服系统流程图

flowchart TD
    A([用户进入客服系统]) --> B[/输入问题/]
    B --> C[输入预处理
分词 / 去噪 / 拼写纠正]
    C --> D{意图识别}
    D -->|常见业务咨询| E[知识库检索]
    D -->|投诉建议| H
    E --> F{是否命中答案}
    F -->|是| G[生成并返回回答]
    F -->|否| H[转接人工坐席]
    G --> I{用户是否满意}
    I -->|满意| J([会话结束
记录日志])
    I -->|不满意| H
    H --> K[人工处理并回复]
    K --> J
    J --> L[(会话数据入库
用于模型优化)]

图二　智能客服系统 ER 图

erDiagram
    CUSTOMER ||--o{ CONVERSATION : "发起"
    AGENT ||--o{ CONVERSATION : "接待"
    CONVERSATION ||--|{ MESSAGE : "包含"
    CONVERSATION ||--o| TICKET : "生成"
    KB_ARTICLE ||--o{ MESSAGE : "命中引用"
    CUSTOMER {
        bigint customer_id PK "客户编号"
        varchar nickname "昵称"
        varchar phone "手机号"
        datetime register_time "注册时间"
    }
    AGENT {
        bigint agent_id PK "坐席编号"
        varchar name "坐席姓名"
        varchar group_name "业务分组"
        int status "在线状态"
    }
    CONVERSATION {
        bigint conversation_id PK "会话编号"
        bigint customer_id FK "客户编号"
        bigint agent_id FK "坐席编号"
        tinyint channel "来源渠道"
        tinyint type "机器人或人工"
        datetime start_time "开始时间"
        datetime end_time "结束时间"
    }
    MESSAGE {
        bigint message_id PK "消息编号"
        bigint conversation_id FK "会话编号"
        tinyint sender "发送方"
        varchar content "消息内容"
        bigint kb_id FK "命中的知识条目"
        datetime send_time "发送时间"
    }
    KB_ARTICLE {
        bigint kb_id PK "知识条目编号"
        varchar title "问题标题"
        text answer "标准答案"
        varchar intent "所属意图"
        int hit_count "命中次数"
    }
    TICKET {
        bigint ticket_id PK "工单编号"
        bigint conversation_id FK "会话编号"
        varchar title "工单标题"
        tinyint status "处理状态"
        varchar result "处理结果"
        datetime create_time "创建时间"
    }
