Web 前端的长度单位

CSS 中常用的长度单位分类与示例

px（像素）
绝对单位

最常用的单位，1px 表示屏幕上的一个物理像素点。

宽度: 150px
%
相对单位

相对于父元素的百分比，常用于流式布局。

75%
em
相对单位

相对于当前元素字体大小的倍数。此处 font-size: 20px。

2em
rem
相对单位

相对于根元素 (html) 字体大小的倍数，避免嵌套影响。

2rem
vw / vh
视口单位

相对于视口宽/高度的百分比。1vw = 视口宽度的 1%。

50vw
vmin / vmax
视口单位

取视口宽高中较小/较大值的百分比。

50vmin × 自动
pt / pc
绝对单位

印刷单位。1pt = 1/72 英寸，1pc = 12pt。多用于打印样式。

12pt 文字
ch / ex
相对单位

ch 基于 "0" 字符宽度，ex 基于小写字母 "x" 的高度。

ch: 0 0 0 0 0

单位对照表

单位类型参考基准常见用途
px绝对物理像素边框、字号、定位
%相对父元素尺寸流式布局、响应式宽度
em相对当前元素 font-size行高、内边距缩放
rem相对根元素 font-size统一字号、间距系统
vw / vh视口视口宽 / 高全屏布局、大标题
vmin / vmax视口视口宽高的最小/最大值保持比例的元素
pt绝对1/72 英寸打印样式
