异步流程演示：包饺子

Promise + async/await · setTimeout 模拟每步耗时 · 和面 / 和馅 用 Promise.all 并行

返回首页

① 实现思路 把每个流程包装成一个 Promise

const lh_task = (name, ms) => new Promise(resolve =>
  setTimeout(() => resolve(name), ms)   // setTimeout 模拟耗时
);

async function lh_cook() {
  await lh_task('买原料', 6000);              // 依次：等它做完才走下一步
  await lh_task('取原料', 2000);
  await Promise.all([                       // 并行：同时开跑，都完成才继续
    lh_task('和面', 5000),
    lh_task('和馅', 3000)
  ]);
  await lh_task('包饺子', 4000);
  await lh_task('吃饺子', 1000);
}

② 流程演示 总耗时 ≈ 6+2+5+4+1 = 18 秒（并行只算较慢的和面）
