JavaScript 两种定时器

setTimeout（延时一次性）与 setInterval（周期循环）—— 交互演示

返回首页

① 两种定时器对比 一个是闹钟，一个是心跳

setTimeout
像闹钟：定好时间，到点只响一次就结束。返回一个定时器 ID，可用 clearTimeout(id) 提前取消。
const id = setTimeout(() => {
  console.log('3 秒后执行，只执行这一次');
}, 3000);

clearTimeout(id); // 反悔，不执行了
setInterval
像心跳：每隔固定时间跳一次，永不停止，直到 clearInterval(id) 叫停。适合时钟、轮询、动画。
const id = setInterval(() => {
  console.log('每 1 秒执行一次');
}, 1000);

clearInterval(id); // 停止循环
